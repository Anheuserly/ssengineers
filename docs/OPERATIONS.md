# Operations Checklist

## Before release

- [ ] Confirm `SS_ENGINEERS_BUSINESS_ID` points to S.S. Engineers & Consultants.
- [ ] Confirm the database route can insert into `work_requests` and `work_request_targets`.
- [ ] Submit one non-production request and verify it is assigned directly to the S.S. Engineers business.
- [ ] Confirm genuine media is attached only to the correct listing before publishing it.
- [ ] Test service bucket selection, removal and submission in a private browser window.
- [ ] Test cookie accept, reject and customise flows after a hard refresh.
- [ ] Run `npm run build`.

## Editorial rules

- Do not add prices to services that require site review.
- Do not use general site/project photos as listing photos.
- Keep service names aligned with the central database catalogue.
- Record site drawings, photos and documents through the request process, not in browser storage.
